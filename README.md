# arduino-control

Пульт для управления самолётом по радиоканалу на Arduino UNO.

## Статус проекта

Заготовка: мигание встроенным светодиодом.

## Требования

- VS Code
- Arduino IDE (установленная в `C:\Program Files\Arduino IDE\`)
- Arduino UNO
- USB-кабель для подключения платы

## Прошивка из VS Code по горячим клавишам

Проект настроен на работу с встроенным `arduino-cli.exe` из Arduino IDE.

### Горячие клавиши

| Клавиши        | Действие                                |
|----------------|-----------------------------------------|
| `Ctrl+Shift+B` | Компиляция скетча                       |
| `Ctrl+Alt+B`   | Компиляция + прошивка на плату (COM7)   |

> **Примечание:** Порт `COM7` захардкожен в задачи VS Code (`.vscode/tasks.json`). Если плата определяется на другом порту, проверьте порт командой `arduino-cli board list` и обновите файл.

### Как это работает

1. **`.vscode/tasks.json`** — две задачи:
   - `Arduino: Компиляция` — компилирует скетч для Arduino UNO (`arduino:avr:uno`).
   - `Arduino: Прошивка (Upload COM7)` — компилирует и загружает прошивку через COM7.
2. **`keybindings.json`** (VS Code, пользовательский) — назначает горячие клавиши на запуск этих задач, когда открыт файл `.ino`.

### Загрузка вручную через Arduino IDE

1. Откройте файл `arduino-control/arduino-control.ino` в Arduino IDE.
2. Подключите Arduino UNO через USB.
3. Выберите плату: **Инструменты → Плата → Arduino Uno**.
4. Выберите порт: **Инструменты → Порт → COM7**.
5. Нажмите кнопку **Загрузка**.

После загрузки встроенный светодиод на плате (пин 13) начнёт мигать с периодом 0,5 секунды.

## Структура проекта

- `arduino-control/arduino-control.ino` — основной скетч
- `.vscode/tasks.json` — задачи VS Code для компиляции и прошивки
