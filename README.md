# arduino-control

Пульт для управления самолётом по радиоканалу на Arduino UNO.

## Статус проекта

Заготовка: мигание встроенным светодиодом.

## Требования

- Arduino IDE (или PlatformIO)
- Arduino UNO
- USB-кабель для подключения платы

## Загрузка на плату

1. Откройте файл `arduino-control/arduino-control.ino` в Arduino IDE.
2. Подключите Arduino UNO через USB.
3. Выберите плату: **Инструменты → Плата → Arduino Uno**.
4. Выберите порт: **Инструменты → Порт → (нужный COM-порт)**.
5. Нажмите кнопку **Загрузка**.

После загрузки встроенный светодиод на плате (пин 13) начнёт мигать с периодом 0,5 секунды.
